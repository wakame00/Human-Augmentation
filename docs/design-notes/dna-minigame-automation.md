# DNA工程ミニゲーム・自動化設計メモ

## 実装単位

全工程を一度に作らず、共通の`DnaTaskSession`を先に作り、工程ごとの画面を追加する。

想定する共通状態:

- プレイヤーUUID
- 対象装置座標
- DNA採取元
- 工程ID
- サーバー生成seed
- 開始tickと制限時間
- 入力回数、ミス回数、品質、汚染
- 完了・中断・自動処理フラグ

## ネットワーク原則

- サーバーがセッションを作成する。
- クライアントは操作入力だけ送る。
- サーバーが順序、距離、装置所有、時間、投入素材を再検証する。
- 画面を閉じた場合は一定時間再開可能にするか、安全中断して素材を保持する。
- ログアウト・装置破壊時の処理を必ず定義する。

## 最初に実装する試作

遠心分離バランスを最初の試作とする。

- 6か所の試験管スロットを円形配置。
- 試験管には1～3の重量がある。
- 対向位置の合計差を許容値以内へ収める。
- 確定ボタンでサーバーが配置を採点する。
- 完全均衡で品質100%、許容内で85%、不均衡は再試行または品質低下。

この工程は反射神経や文字入力へ依存せず、GUIスロットとボタンの同期試験に向いている。

## 自動化との共通化

各工程は最終的に`DnaTaskResult`を返す。

```text
success
quality 0..100
contamination 0..100
energyUsed
reagentUsed
```

手動GUIも自動設備も同じ結果をDNAサンプルへ適用する。自動設備だけの別レシピを増やさず、処理の入口を共通化する。
