# 手術設備のマルチブロック化

将来、現在の単体手術台を中心ブロックとするマルチブロック設備へ拡張する。

## 目的

- 高性能な人体改造へ進むための設備進行を作る。
- 手術台を置くだけで終盤改造を装着できないようにする。
- 工業・魔法・DNA・人体炉など、異なる改造系統の専用設備を追加できるようにする。

## 仮の設備段階

### Tier 1: 簡易手術台

- 心臓、肺など基本的な臓器のみ。
- 低容量の人工器官を装着・取り外し可能。
- DNA編集、特殊器官、危険物は扱えない。
- 手術失敗や拒絶反応の危険が比較的高い。

### Tier 2: 無菌手術室

- 手術台、医療機器、照明、生命維持装置で構成。
- 骨格、筋肉、皮膚、血液、脊椎を扱える。
- 安定度の高い手術と複数改造の管理が可能。
- 基礎的なDNA治療を解禁。

### Tier 3: 遺伝子研究設備

- DNA解析機、培養槽、遺伝子編集装置を追加。
- Mob DNAの解析、遺伝子抽出、組み換え、欠点除去を解禁。
- 高度なDNAや他Mod由来DNAには追加設備を要求する。

### Tier 4: 高度人体改造施設

- 強力な人工臓器、追加器官、魔法器官、工業系インプラントを扱える。
- Oritechなどの外部Mod設備と連携可能。
- 電力、冷却材、薬品、魔力などを継続的に要求する。

### Tier 5: 人体炉施設

- Mekanism人体核分裂炉・核融合炉の装着と整備を解禁。
- 放射線遮蔽、冷却、廃棄物回収、緊急停止設備を必須にする。
- 設備不備の場合は手術不可、または重大事故の危険を持たせる。

## 制限に使う項目

- 変更可能な身体部位
- 改造のTierと占有容量
- 同時手術数
- 手術成功率と拒絶反応率
- DNA品質と編集可能な遺伝子数
- 放射性・魔法・機械器官の取扱許可
- 電力、冷却、無菌度、薬品、生命維持能力

## UIとの関係

身体スロットUIは共通で使用し、現在のマルチブロック設備が扱えないスロットをロック表示する。ロックへカーソルを合わせると、不足している設備や必要Tierを表示する。

## 未決定事項

- マルチブロックの具体的な形状と可変構造の可否。
- 手術中にプレイヤー本人が設備へ入るか、他プレイヤーが操作するか。
- 設備不足時に単に拒否するか、低成功率で強行できるか。
- Create、Oritech、Mekanism、魔法Mod設備を構造条件に含めるか。
# 箱型手術キャビン（現行試作）

手術台を基準 `(0,0,0)` とする、水平4方向へ回転可能な3×4×3構造。

- 中央床：手術台
- 東西：同Tierの手術アーム
- 北床：かまど式動力入力
- 南中央：入口。床は医療フレーム、上2ブロックは空気
- 周囲2段：同Tierの医療フレーム
- 3×3天井：同Tierの医療フレーム
- T2のみ北壁下段中央：精密制御モジュール

設置時にプレイヤーが向いていた方向がキャビンの背面になり、入口は反対側に作る。
キャリブレーターは後続実装。
