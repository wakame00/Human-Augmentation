# Create連携試作

## 内容

- `T2 動力筋肉（Create連携）` を本体アイテムとして登録する。
- Create導入時だけ条件付きクラフトレシピを読み込む。
- 材料はCreateの安山岩合金と精密機構、およびT1人工筋肉。
- 推奨部位では攻撃速度と移動速度を増加する。
- 誤った部位に置いた場合は既存仕様どおり性能50%。
- 重複時は既存仕様どおり100%、50%、25%……と減衰する。
- T2部位なのでT2以上の手術設備が必要。

## 遮断動作

- Create未導入：レシピを読み込まず、本体は通常起動する。
- Create導入済みだが必要アイテムが改名・削除：`neoforge:registered` 条件が失敗し、
  レシピを読み込まない。
- 動力筋肉の本体アイテムと保存IDはHuman Augmentation側にあるため、
  既に装着済みのデータは消えない。

## 今回扱わないもの

- Create Java APIの直接呼び出し。
- 回転力の受け取り。
- Ponder表示。
- Sequenced Assembly。

この試作で条件付きデータ連携の安全性を確認した後、回転力対応を別段階で実装する。
