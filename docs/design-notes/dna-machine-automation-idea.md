# DNA装置のティア・自動化構想（案）

この文書は将来案であり、現時点の確定仕様ではない。

## 基本方針

- 初期Tierでは工程を手作業で進め、DNA処理の流れをプレイヤーに理解させる。
- Tierとアップグレードモジュールによって、試薬投入、処理、搬出を段階的に自動化する。
- 装置本体を毎回置き換える方式と、同じ本体へモジュールを追加する方式のどちらにするかは未確定。
- 通常動力はFEとし、将来のCreate連携では一部工程を回転力へ置き換えられるようにする。

## Tier案

### T1：手動式

- サンプル、抽出試薬、増幅ミックス、滅菌注射器を工程ごとに手動投入する。
- FEの外部入力には対応する。
- 完成品は手動で回収する。

### T2：半自動式

- 試薬専用スロットを追加する。
- 抽出、増幅、解析を順番に自動進行する。
- 完成品は手動回収とする。

### T3：完全自動式

- アイテムの自動搬入・搬出に対応する。
- FEと試薬があれば連続処理できる。
- AE2、Mekanism、Ender IOなどの物流設備との接続を想定する。

### T4：遺伝子編集

- 解析済みDNAから特定の遺伝子を選択・分離できる。
- 不要遺伝子の除去や、複数採取元の遺伝子合成を解禁する。
- 汚染、拒絶反応、変異リスクを導入する候補Tierとする。

### T5：高度培養・量産

- 保存したマスターDNAから遺伝子注射を複製できる。
- 特殊DNAや高TierのMod連携DNAを処理できる。
- 並列処理や量産に対応する。

## アップグレード候補

- オートピペット：試薬を自動投入する。
- 遠心分離モジュール：抽出工程を自動化する。
- PCRモジュール：増幅速度または成功率を向上する。
- シーケンサーモジュール：解析工程を自動化する。
- 無菌処理モジュール：汚染率を低下させる。
- 搬出入モジュール：ホッパーやパイプによる自動搬送を解禁する。
- 並列処理モジュール：複数サンプルを同時処理する。

## Mod連携候補

- Create導入時は、低Tierの遠心分離工程を回転力で実行できる。
- Createを使用すると設備が大型化する代わりに、初期のFE機械レシピを軽減できる案も残す。
- AE2、Mekanism、Ender IOなどはT3以降の自動搬送と接続する。

## 未決定事項

- 装置本体をTierごとに交換するか、モジュールで成長させるか。
- 各TierのFE消費量、処理時間、汚染率。
- アップグレードスロット数と同種モジュールの装着上限。
- Create連携を便利な代替手段にするか、より複雑な高効率手段にするか。
